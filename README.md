# OpenModularPassiveDefense

Repo for [OpenModularPassiveDefense](https://www.curseforge.com/minecraft/mc-mods/ompd) for Minecraft 1.12.2 (Forge).

OpenModularPassiveDefense adds passive defenses that complement [OpenModularTurrets](https://www.curseforge.com/minecraft/mc-mods/openmodularturrets): blocks that keep mobs and intruders out of your base without needing power or ammo.
If you need help, ask us in our [Discord](https://discord.gg/SEG695u).

## Features

- **Hardened blocks** in 5 tiers, increasingly resistant to explosions and mining
- **Hardened walls** and **fences** in 5 tiers; fences damage whoever touches them
- **Camouflage trap:** disguised as any block, it is solid for you and your trusted players, while everyone else falls through it into whatever you build below

## Requirements

- Minecraft 1.12.2 with Forge
- [OMLib](https://www.curseforge.com/minecraft/mc-mods/omlib) ([GitHub](https://github.com/OpenModularTurretsTeam/OMLib)), required
- [OpenModularTurrets](https://www.curseforge.com/minecraft/mc-mods/openmodularturrets), optional
